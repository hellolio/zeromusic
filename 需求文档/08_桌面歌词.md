# 08 · 桌面歌词 需求文档

> 版本：v1.0 ｜ 关联构架：整体构架.md ｜ 平台：**仅桌面端**（macOS / Windows / Linux）

---

## 1. 功能概述

**桌面歌词**是一根独立于主窗口的系统级「歌词条」窗口：**背景完全透明**、**始终置顶于所有应用之上**，随播放进度**逐行滚动**显示当前歌词。面向"边工作边听歌"的场景——主窗口最小化、被遮挡甚至关闭到后台时，歌词条仍持续显示并滚动。歌词条右端提供 **✕ 关闭按钮**，随时一键关闭。

对标 macOS 顶栏歌词 / 网易云音乐桌面歌词的形态，视觉遵循本项目 iOS 风 Design Token（描边白字 + accent 高亮）。

## 2. 界面布局

```
（桌面 · 悬浮于任意应用之上）
      ═══════ 屏幕上其他应用的内容 ═══════
 ┌───────────────────────────────────────────┐
 │                                           │  ← 无边框 · 无标题栏
 │  ♪ 这是一句正在演唱的歌词（大字·高亮）   ✕ │     背景完全透明
 │    接下来的一句歌词（小字·半透明）          │     平时只见文字与 ✕
 │                                           │
 └───────────────────────────────────────────┘
        ↑ 鼠标悬停时浮现极淡底色，便于定位与拖动
```

- 无窗口边框 / 标题栏 / 阴影底板；**不占据任务栏 / Dock 图标**。
- 默认尺寸：约 720 × 96（宽 × 高，随字号档位微调）；默认位置：屏幕底部居中偏下。

## 3. 功能需求

### 3.1 窗口形态（核心）

- **独立窗口**：与主窗口完全独立的 OS 级窗口（独立 Flutter 引擎实例），二者生命周期互不阻塞：
  - 主窗口最小化 / 隐藏 → 歌词条继续显示与滚动；
  - 关闭歌词条 → 主窗口与播放完全不受影响；
  - 应用整体退出 → 歌词条随进程一并关闭。
- **背景完全透明**：窗口无任何底色 / 毛玻璃 / 边框，仅歌词文字与 ✕ 按钮可见（文字带描边或投影，保证在任意壁纸上可读）。
- **永远置顶**：always-on-top，位于普通应用窗口之上（不承诺盖过全屏独占游戏/视频）。
- **不抢焦点**：点击歌词条不得夺走当前应用焦点（不可聚焦窗口）。
- 位置自由：按住歌词条空白处**拖动**定位；位置持久化，重启恢复；跨显示器拖出虚拟桌面范围时钳制回可见区域。

### 3.2 歌词显示

- **内容两行**：当前行（大字、高亮）+ 下一句（小字、半透明），构成"滚动预览"式歌词条。
- 数据源与 02 播放页**共用同一歌词链路**（LRC 解析 + 播放进度 → 当前高亮行），表现一致。
- **逐行滚动**：行切换时旧句上滑淡出、新句自下滑入；拖动 seek 或切歌时**立即**切换到对应行。
- 暂停：停在当前行不动；恢复播放继续滚动。
- 无歌词：显示「歌名 · 歌手」占位。
- 无当前曲目：显示「未在播放」占位（歌词条保留，可拖动、可 ✕）。
- 纯音乐间奏（可选）：显示「♪ ~ 间奏 ~」。

### 3.3 ✕ 关闭按钮

- 位置：歌词条**右端**，垂直居中；平时低透明度常显，悬停变亮（保证可见性与可测性）。
- 点击：销毁歌词条窗口；设置页「桌面歌词」开关**同步置为关**并持久化；播放不中断。

### 3.4 设置入口

- 设置页新增「桌面」分组 →「桌面歌词」开关（**仅桌面端显示该项**）：
  - 开：创建 / 显示歌词条；关：关闭歌词条。切换即时生效。
- 可选设置项（同分组）：字号档位（小 / 中 / 大）、恢复默认位置。
- **记忆**：偏好持久化；应用启动时若开关为开，自动恢复歌词条。

### 3.5 交互边界

- 单击歌词文字：无任何行为（预留双击锁定 / 鼠标穿透，本期不做）。
- ✕ 按钮区域除外，整条均可作为拖动把手。

## 4. 平台差异

| 平台 | 透明窗口 | 置顶 | 备注 |
|------|----------|------|------|
| macOS | NSWindow `opaque=false` + 透明背景色 | `NSFloatingWindowLevel` 级别 | 可选跨所有 Space / 全屏辅助显示 |
| Windows | 分层透明窗口（如 `WS_EX_LAYERED`） | `TOPMOST` | 注意 Per-Monitor DPI 缩放下字号与坐标换算 |
| Linux | 依赖窗口管理器合成器 | 置顶 hint | 无合成器的环境**降级**为深色半透明条，不视为缺陷 |

**统一降级策略**：任何平台无法实现透明或置顶失败时，降级为普通小窗显示歌词，并在设置页开关下方以辅助文案提示当前降级状态；**禁止 crash 或静默无响应**。

## 5. 动画要求

- 行切换：上滑 + 交叉淡入淡出，200–300ms，ease-out / spring，**可中断**。
- 悬停淡底浮现：120–200ms 淡入淡出。
- ✕ 悬停：透明度提升 + 轻微放大（微交互 ≤ 200ms）。
- 全部遵循整体构架 §5 动画规范；系统开启「减弱动态效果」（`MediaQuery.disableAnimations`）时全部降级为直接替换。

## 6. 数据模型与数据流（跨窗口）

### 6.1 偏好扩展

`AppPreferences`（沿用现有 preferences store 持久化）新增：

```
desktopLyricsEnabled  bool    默认 false
desktopLyricsFontSize 档位枚举 小/中/大（可选，默认中）
desktopLyricsOffset   double? 歌词条位置（x, y；null = 默认底部居中）
```

### 6.2 数据流（单一事实源 = 主窗口）

```
主窗口（唯一事实源，持有 DB / AudioEngine / 歌词仓库）
  audioControllerProvider(position, currentTrack)
    + lyricsLinesProvider（复用 02 歌词链路）
    → 计算当前行（与 activeLyricIndexProvider 同一套逻辑）
    → 行变化 / 切歌 / 暂停态变化时，经窗口通道推送消息
        LyricBarMessage { type, 当前句, 下一句 }
            ↓  跨窗口通道（平台通道 / 多窗口框架消息）
歌词条窗口（纯渲染，零业务）
  只消费消息驱动 UI；不持有数据库、不持有音频引擎、不落库
```

- **节流**：仅在行变化 / 切歌 / 状态切换时推送，禁止逐帧推送（对齐构架 §5.3 节流约束）。
- **反向通道**：歌词条内 ✕ → 通知主窗口将开关置为关（偏好写回仍只发生在主窗口）。

## 7. 实现架构（建议，最终以开发方案为准）

```
lib/services/desktop_lyrics/
├── desktop_lyrics_controller.dart   # Riverpod Notifier：开关状态、读写偏好、调用窗口接口
├── lyric_window_api.dart            # 抽象接口：open / close / updateLine / restorePosition
├── lyric_window_desktop.dart        # 桌面平台实现（候选：desktop_multi_window + window_manager）
└── lyric_bar_messenger.dart         # 跨窗口消息编解码
lib/ui/desktop_lyrics/
└── desktop_lyrics_bar.dart          # 歌词条 UI（独立窗口入口，轻量 Material App）
```

- 遵循构架 §6 铁律：平台特定实现全部藏在 `LyricWindowApi` 接口后，业务层零感知；测试注入 fake。
- 新增桌面端依赖（候选，开发方案阶段定稿）：`desktop_multi_window`（第二窗口）、`window_manager`（窗口属性：透明 / 置顶 / 无边框）。
- 本地化：新增文案（桌面歌词、未在播放、间奏等）——按规矩同步更新 `AppStrings` 基类 + 中 / 英 / 日 3 份语言文件。

## 8. 验收要点 / 测试用例范围

- 窗口形态：独立于主窗口、背景全透明、始终置顶、无边框、不进任务栏、不抢焦点（macOS / Win / Linux 手工验证）。
- 歌词：逐行滚动与 02 播放页一致；切歌 / seek 立即刷新；暂停静止；无歌词 / 无曲目占位正确。
- ✕ 按钮：点击关闭歌词条、设置开关同步为关且持久化、播放不中断。
- 设置：开 → 出现、关 → 消失、重启记忆；仅桌面端可见该设置项。
- 拖动：位置可移动、重启恢复、不出屏。
- 主窗口最小化 / 隐藏后歌词条仍滚动。
- 可自动化部分：行计算与消息编解码单测；`DesktopLyricsBar` 各状态（正常行 / 无歌词 / 无曲目 / ✕ 点击回调）widget 测试；窗口创建与销毁走 fake `LyricWindowApi`，**widget 测试不触碰真实平台窗口**（对齐仓库测试约定）。
- 完整用例见《测试用例/桌面歌词_测试用例.md》。
