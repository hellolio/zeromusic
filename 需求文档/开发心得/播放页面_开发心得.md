## 二、功能实现概要

- 实现了哪些功能点
  - 全屏沉浸式播放页：**背景 = 磨砂模糊 + 动态色板**（有封面 = 模糊大图；无封面 = 整层高斯模糊上叠加随机径向光斑，按档位渲染 5/8/12 个）
  - 背景效果三档（省电/均衡/绚彩）联动设置页，持久化在 `AppPreferences.backgroundEffect`
  - 旋转封面（播放中转、暂停停、减弱动效静止）
  - 歌名 · 歌手 · 专辑、可拖动进度条（拖动气泡实时时间 + 手柄放大反馈 + seek）
  - ⏮ ▶/⏸ ⏭ 控制行；🔁 播放模式切换（顺序/循环/单曲循环/随机）
  - 播放队列 bottom sheet（当前高亮、点行切歌）；歌词面板占位「暂无歌词」
  - 收藏 ♥ / ⋯ / 睡眠定时：占位不可点（`onPressed:null`）
  - 空媒体库空态
- 涉及的核心组件 / 服务 / 数据模型
  - `lib/ui/pages/player/player_background.dart`（`pickPalette` 纯函数 + `BackgroundEffectLevel` 档位映射 + `AnimatedPaletteBackground`）
  - `lib/ui/pages/player/player_page.dart`（页面主体、旋转封面、进度条、队列/歌词 sheet）
  - `lib/ui/pages/settings/settings_sheets.dart`（档位选择菜单）+ `settings_page.dart`（行）
  - `lib/services/preferences/preferences_controller.dart`（新增 `backgroundEffect` 字段与三档枚举）
  - `lib/services/audio/audio_controller.dart`（新增 `PlaybackMode` 枚举与 `cyclePlaybackMode`，模式化 next/previous/完成处理，可注入 `Random`）
  - 本地化：base + zh/en/ja 新增字符串
- 关键技术点
  - 无封面「磨砂多彩」：整层一个 `ImageFiltered(ImageFilter.blur)` 基座 + 色板光斑；按 `track.id.hashCode` 确定性派生高饱和色板，光斑围绕色板色带 ±Hue 偏移/明度递减分层，单 `AnimationController` 循环漂移；同曲稳定、切歌换色板
  - 档位映射：`BackgroundEffectLevel → (paletteCount, blur, cycle, paletteShift)`，仅影响静态参数，widget 结构不变
  - 光斑通过 `Positioned.fill` + 带 `RadialGradient` 的 `DecoratedBox` 渲染，blur 层 key 固定 `palette-blur-layer`，测试按 key 圈定断言
  - 播放 14s/圈、暂停 36s/圈（呼吸变慢）、无曲目静态默认色
  - 所有持续动画一律以 `MediaQuery.disableAnimationsOf(context)` 守卫

## 三、遇到的问题与解决（坑）

### 坑 1：持续 AnimationController 导致 widget 测试 `pumpAndSettle` 死锁
- **现象**：测试环境 `wrapApp` 用 `_NoAnimations` 强制 `disableAnimations: true`，但若背景/旋转直接用 `repeat()`，`pumpAndSettle` 永不结束。
- **原因分析**：`pumpAndSettle` 等待所有帧调度结束；无限循环动画永远有挂起的帧。
- **解决过程**：参考迷你条 `_Equalizer` 的既有做法——先读 `MediaQuery.disableAnimationsOf(context)`，为 true 时 `stop()` 且不 `repeat()`。
- **最终方案**：`didChangeDependencies`/`didUpdateWidget` 里统一 `_sync()`；disableAnimations 或非播放态 → `stop()`，否则才 `repeat()`。测试因此 `pumpAndSettle` 可收敛。
- **经验**：凡应用内“无限循环”动效（转盘、呼吸、均衡条）必须挂在 disableAnimations 下，否则测试环境必挂。

### 坑 2：引擎事件流异步投递导致顺序错乱（isPlaying 断言 flaky）
- **现象**：sequential 队尾完成测试里 `emitCompleted()` 后 `isPlaying` 仍为 true。
- **原因分析**：`StreamController.broadcast()`（非 sync）的事件是**异步投递**的。手动 next 到底后 reload 产生的 `playing(true)` 事件还悬在队列里，`_onComplete()`（收到 completed 后置 false）先执行，随后迟到的 `playing(true)` 又把它覆盖回 true。
- **解决过程**：在两次 reload 之后、`emitCompleted()` 之前先 `await pumpEventQueue()` 把 in-flight 事件冲刷干净。
- **最终方案**：测试里“引擎事件之间”显式 flush；生产代码顺序无影响。
- **经验**：写音频状态测试时，引擎注入的事件与状态断言之间务必 `pumpEventQueue()`/`pump()` 冲刷，避免跨流投递时序干扰。

### 坑 3：NotifierProvider `overrideWith` 不允许带 ref 的工厂
- **现象**：`audioControllerProvider.overrideWith((ref) => AudioController(random: Random(7)))` 编译报 `argument_type_not_assignable`，期望 `AudioController Function()`。
- **原因分析**：`NotifierProvider.overrideWith` 的 create 是**无参**的 `NotifierT Function()`。
- **最终方案**：定义子类 `class _SeededAudioController extends AudioController { _SeededAudioController() : super(random: Random(7)); }`，用 `overrideWith(_SeededAudioController.new)`。
- **经验**：要给 Notifier 注入依赖，走构造函数参数 + 子类 tear-off，别试图传 ref。

### 坑 4：`Override` 类型不来自 flutter_riverpod
- **现象**：`List<Override>` 报 `Override isn't a type`。
- **原因分析**：`Override` 由 `package:riverpod/misc.dart` 导出，flutter_riverpod 未直接 re-export（widget_test.dart 已这样导入）。
- **最终方案**：`import 'package:riverpod/misc.dart' show Override;`。
- **经验**：照抄仓库既有测试的 import 清单最稳。

### 坑 5：新建 PlaybackState 时丢失 playbackMode
- **现象**：`_playAtIndex`/`playQueue` 直接 `PlaybackState(...)` 构造，新字段 `playbackMode` 会回落到默认 `loopAll`，切歌即失忆。
- **最终方案**：两处构造都显式携带 `playbackMode: state.playbackMode`。
- **经验**：给不可变状态类加字段时，全仓搜所有“直构”点，别只加 copyWith。

### 坑 6：页面与迷你条图标重复导致 finder 歧义
- **现象**：`find.byIcon(CupertinoIcons.forward_end_fill)` 命中迷你条与播放页两处（迷你条只是 Opacity 0 仍挂树）。
- **最终方案**：测试统一 `find.descendant(of: find.byType(PlayerPage), ...)` 圈定作用域。
- **经验**：全局组件的子控件测试必须限定父作用域。

### 坑 7：全屏模糊必须“单层”渲染，且档位只调静态参数
- **现象**：若给每个光斑各自套 `ImageFiltered`，全屏多路高斯模糊在真机 GPU 上开销翻倍。
- **最终方案**：整层只有一个 `ImageFiltered` 基座（key `palette-blur-layer`），光斑是基座内部无 blur 的 `RadialGradient` 圆片；三档（省电 5/均衡 8/绚彩 12）只改变光斑数、blur sigma、动画周期与色相偏移量等**静态参数**，widget 树结构不变。
- **经验**：模糊类视觉先定“模糊层数量=1”的结构红线，再谈内容丰富度；性能取舍做成偏好档位而不是写死。

## 五、动画实现要点

- 组件与曲线：`AnimationController.repeat()`（背景光斑漂移、封面旋转）、`AnimatedBuilder`（背景 repaint）、`AnimatedSwitcher`+`ScaleTransition`（播放/暂停图标）、`AnimatedScale`（拖动手柄反馈）；模糊层为静态 `ImageFiltered`（不逐帧重建），仅光斑布局随控制器插值
- 流畅保证：单一控制器驱动插值、色板参数在 build 前确定（`pickPalette` 纯函数），无 setState 逐帧改色；disableAnimations 时全部静止
- 档位与动画：`reduceMotion=true` 或档位=省电时周期加长、偏移最小；`disableAnimations` 直接停转
- 卡顿：无（测试环境动画静止，真机待人工验证帧率）
