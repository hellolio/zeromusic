## 二、功能实现概要

- 实现功能点：
  - 主题三态（浅色/深色/跟随系统）：设置页切换 → `MaterialApp.themeMode` 即时生效（AnimatedTheme 淡变）。
  - 语言中/英/日：切换全部文案即时变化；行值与弹层选中态显示**当前生效语言**。
  - 减弱动态效果：`CupertinoSwitch` → 偏好 → `main.dart` 在 `MaterialApp` 外层包 `MediaQuery(disableAnimations:)`，全应用动画统一降级。
  - 默认音量：滑杆 0–100% → `defaultVolume` 偏好 → `AudioEngine.setVolume` 全链路生效（非摆设）。
  - 关于：版本号 + `showLicensePage` 开源许可入口。
  - 账号 / 缓存清理：按任务约束不开放。
- 核心组件/服务：
  - `preferences_controller.dart`：`AppPreferences` 模型、`PreferencesStore`（`SharedPreferencesStore` 真实实现 + 可注入 provider）、`AsyncNotifier` 控制器（`setThemeMode/setLocale/setReduceMotion/setDefaultVolume`，乐观更新 + 异步落盘）。
  - `audio_controller.dart`：`ref.listen(preferencesProvider)` 把音量偏好镜像到引擎。
  - `settings_page.dart`（ConsumerWidget 无状态列表）+ `settings_sheets.dart`（主题/语言选择：移动毛玻璃 BottomSheet / 桌面锚点 showMenu）。
- 平台差异：同一 ListView 布局；选择交互按 `>= 840` 断点自适应；列表进入做淡入+位移动画并在减弱动效时置零。

## 三、遇到的问题与解决（坑）

### 坑 1：Riverpod 3 的 `AsyncValue.valueOrNull` 不存在
- **现象**：`flutter analyze` 报 `The getter 'valueOrNull' isn't defined`。
- **原因分析**：把 `Notifier` 升级为 `AsyncNotifier` 后，误按 Riverpod 2 记忆写 `valueOrNull`；看源码发现 Riverpod 3 已合并该语义，`value` 直接返回 `ValueT?`（不抛错），`requireValue` 才抛。
- **解决过程**：grep pub-cache 里 `async_value.dart:557` 确认 `ValueT? get value`。
- **最终方案**：把 5 处 `.valueOrNull` 全部替换为 `.value`。
- **经验**：升级大版本先查 `Ref`/`AsyncValue` 源码，别背旧 API。

### 坑 2：`ref.listen` 回调内调用 `ref.read`(经 getter) 被 Riverpod 断言拦截且静默吞错
- **现象**：TC-09 断言 `engine.lastVolume == 1.0` 拿到 null；测试不报异常，纯静默。
- **原因分析**：`AudioController.build()` 里 `ref.listen(preferencesProvider, ...)`，回调内 `_applyVolume()` 经 `_engine` getter 执行 `ref.read(audioEngineProvider)`。Riverpod 3 在 `_debugCallbackStack > 0`（生命周期/监听回调）时 `_throwIfInvalidUsage` 断言拦截 `Ref` 使用；该异常被 `container.runGuarded` 兜住仅上报 onError，音量从未生效。
- **解决过程**：先在 build 里缓存 `final engine = ref.read(audioEngineProvider)`，回调只用外层捕获的 `engine` 与 `next.value!.defaultVolume`，不再碰 `ref`。
- **最终方案**：回调完全自包含；另在 build 尾部做一次「启动即应用」兜底，覆盖监听已完成的时序。
- **经验**：**监听/生命周期回调里永远不要 `ref.read`**——把需要的值在 build 里捕获好再进回调。

### 坑 3：`AppLanguage.fromLocale(null)` 与"当前生效语言"不一致
- **现象**：TC-01 找 `English` 找不到；语言行值显示了"中文"。
- **原因分析**：偏好 `locale` 为 null（跟随系统），但 `fromLocale(null)` 兜底返回 `zh`，于是行值显示"中文"而非系统实际的英文。
- **最终方案**：行值与弹层选中态改用 `Localizations.localeOf(context)`（真实生效语言），语义正确且与 MaterialApp 实际一致。
- **经验**："当前语言"应读 `Localizations.localeOf`，偏好字段只负责"想用什么"。

### 坑 4：文案定位的歧义
- **现象**：TC-05 断言 `find.text('设置')` 报"too many"；选"中文"时行值也是"中文"造成 tap 歧义。
- **原因分析**：AppBar 标题与底栏 NavigationBar 都叫"设置"；语言行值与弹层选项文案相同。
- **最终方案**：AppBar 断言用 `find.descendant(of: find.byType(AppBar), ...)` 限定；行值显示生效语言后"中文/English"不再与选项冲突；交互行一律用 `ValueKey` 定位而非正文。
- **经验**：同一文案多处出现时，给可交互元素加 `ValueKey`，断言用祖先范围收窄。

### 坑 5：shared_preferences 平台通道会污染全部既有 widget 测试
- **现象**：`AsyncNotifier.build()` 直接 `SharedPreferences.getInstance()`，任何没初始化 mock 的测试（widget_test / playlist / import / audio_controller）都会撞 MissingPluginException。
- **原因分析**：偏好是全局依赖，注入点一改全部测试暴露在真实插件路径上。
- **最终方案**：仿 `import_io` 的注入模式——`PreferencesStore` 抽象 + `SharedPreferencesStore`（真实）+ `preferencesStoreProvider`（注入点）；`wrapApp` 默认注入 `InMemoryPreferencesStore()`，纯 Dart 的 `audio_controller_test` 也在自己的 `ProviderContainer` 里补 override；SharedPreferences 真实往返单独用 `SharedPreferences.setMockInitialValues` 覆盖。
- **经验**：**引入全局平台依赖时，先想好全量测试的注入面**，只改一处 `wrapApp` 比给每个用例打补丁可靠。

### 坑 6：`CupertinoIcons` 图标名不存在的编译错
- **现象**：`color_swatch`、`volume_lower` 编译期 undefined。
- **最终方案**：换用 `sun_max`、`speaker_2_fill` 等真实存在的图标。
- **经验**：CupertinoIcons 没有 Material 那样的 paint/color_swatch，先核对 icon gallery。

## 五、动画实现要点

- 主题切换：`MaterialApp.themeMode` 原生 AnimatedTheme 颜色淡变，零手写。
- 设置列表进入：`TweenAnimationBuilder` 淡入 + 上移（`AppCurves.standardMotion`，250ms）；`MediaQuery.disableAnimationsOf` 为真时恒等呈现（全程零动画，符合减弱动效）。
- 弹层：BottomSheet 自下而上 + `GlassOverlay` 毛玻璃。
- 减弱动效全局生效：`main.dart` 把 `reduceMotion` 并入环境 `disableAnimations`（保留测试包装层的值），所有读取该标志的动画组件统一降级，无需逐组件改造。

## 六、可复用经验 / 改进方向

- 沉淀：
  - `PreferencesStore` 抽象 + 测试存储注入模式（与 `ImportFileStore` 同构），可直接复用于其它平台依赖。
  - `AsyncNotifier` 乐观更新 + 落盘范式；`ref.listen` 回调自包含写法。
  - "当前生效语言读 `Localizations.localeOf`"的心智模型。
- 改进方向：
  - 均衡器/音质当前为「即将支持」占位，待引擎能力接入后启用。
  - 音量滑杆默认使用 0–1 连续值，后续可支持 dB 刻度或分档。
  - 账号 / 缓存清理 / 标签管理入口按需后续补充。
  - `preferences_controller.dart` 可考虑拆出 store 到独立文件消除与 UI 的耦合（当前同文件避免循环 import）。
