# 01 · 播放列表页面 需求文档

> 版本：v1.0 ｜ 关联构架：整体构架.md ｜ 平台：通用 + 移动/桌面差异

---

## 1. 功能概述

播放列表页面是**主页面**（移动端底栏第 1 项 / 桌面端左侧导航第 1 项），用于浏览、筛选、管理本地已导入的歌曲。支持按多种维度分类、通过**标签系统**自定义分类、点按即播、以及每个歌曲行的右键（⋯）菜单（喜欢 / 删除 / 编辑）。

## 3. 功能需求

### 3.1 分类显示（横向标签切换）
- 默认标签：**全部、艺人、喜欢、最近播放**。
- **全部**：所有已导入歌曲，按文件名/添加时间排序。
- **艺人**：按艺人分组。
- **喜欢**：仅显示已加入喜欢的歌曲。
- **最近播放**：按最近播放时间倒序。
- **标签**：展开自定义标签，见 3.5。
- 切换分类带横向滑动 + 淡入动画。

### 3.2 歌曲行（SongTile）
- 展示：封面缩略图、歌名、歌手、时长。
- **点按**：自动开始播放该歌曲（加入/替换播放队列）。
- 播放中的歌曲高亮显示（accent 色，可加均衡波形象征动画）。
- 右侧固定「⋯」三点按钮，点按弹出上下文菜单（右键菜单）。

### 3.3 右键菜单（⋯ / 长按 / 鼠标右键）
点击「⋯」弹出 `BottomSheet`（移动）或右键菜单（桌面），包含：
- **加入喜欢 / 取消喜欢**（切换图标，红心反馈动画）
- **打标签**（进入标签选择）
- **加入播放队列**（可选）
- **编辑**（见 3.6）
- **删除**（二次确认弹窗）
- **分享 / 导出文件**（可选）

### 3.4 搜索
- 顶部搜索框，按歌名 / 歌手 / 专辑 / 标签实时过滤，输入带动画。

### 3.5 标签系统（自定义分类）
- 用户可**创建 / 重命名 / 删除标签**。
- 可为歌曲**打/取消多个标签**。
- 按标签快速筛选歌曲。
- 数据持久化于本地数据库。
- 标签管理入口：分类栏「标签 ▾」+ 首页「✚新建」。

### 3.6 编辑歌曲信息（编辑弹窗）
编辑字段：
- **歌曲名称（标题）**
- **歌手/艺人**
- **专辑**（可选）
- **类型/流派**（属 GB 标签或自建流派字段）
编辑保存后即时刷新列表。

### 3.7 删除
- 从媒体库移除（可选是否同时删除本地文件），二次确认。

## 4. 平台差异

| 功能 | 移动端 | 桌面端 |
|------|--------|--------|
| 右键菜单 | 长按 / 点「⋯」 | 鼠标右键 / 点「⋯」 |
| 悬停反馈 | 无 | 行 hover 高亮 + 工具提示 |
| 添加歌曲 | 由导入页处理 | 同左 |

## 5. 动画要求
- 分类标签切换：滑动 + 淡入。
- 歌曲行增删：`AnimatedList` 展开/收起。
- 喜欢切换：红心 `AnimatedScale` 弹跳。
- 编辑/删除弹窗：自下而上 + 毛玻璃。

## 6. 数据模型（草案）

```
Song { id, title, artist, album, duration, filePath, coverPath, type, isFavorite, lastPlayedAt, createdAt, tags[] }
Tag  { id, name, color }
```

## 7. 验收要点 / 测试用例范围
- 各分类切换正确。
- 点歌即播、迷你条与播放页状态同步刷新。
- 标签创建/删除/打标签/筛选正确。
- 编辑字段持久化并刷新。
- 删除有确认。
- 右键菜单在移动/桌面均可用。
- 完整用例见《测试用例/播放列表页面_测试用例.md》。
