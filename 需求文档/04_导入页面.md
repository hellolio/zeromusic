# 04 · 导入页面 需求文档

> 版本：v1.0 ｜ 关联构架：整体构架.md ｜ 平台：移动端为主 + 桌面端差异

---

## 1. 功能概述

导入页面（移动端底栏第 2 项 / 桌面端左侧导航第 2 项）用于将音乐导入本地媒体库。支持多种来源：**云端、蓝牙、WiFi、Mac 电脑、Win 电脑**。桌面端则自本机文件系统导入。

## 3. 功能需求

### 3.1 导入来源
| 来源 | 说明 |
|------|------|
| 云端 | 从私有/兼容云盘拉取（需配置账号与授权） |
| 蓝牙 | 从蓝牙设备接收文件（Android/iOS 权限敏感） |
| WiFi | 局域网内从其他设备接收（Web/HTTP 上传） |
| Mac 电脑 | 从同一网络 Mac 传输 |
| Win 电脑 | 从同一网络 Windows 传输 |
| 本机文件（桌面） | 原生文件选择器批量选择 |

### 3.2 导入流程
- 选择来源 → 选择文件/授权 → 显示**导入进度**。
- 支持**批量**导入与断点/排队。
- 失败项可**重试**。
- 导入完成后自动**扫描元数据**（封面、歌名、歌手、时长）并归入媒体库 → 播放列表页可见。

### 3.3 格式支持
- 音频：mp3 / flac / wav / m4a / ogg / opus / aac 等主流格式。
- 稍后由内部音频引擎（just_audio）支持的格式兜底。

### 3.4 状态展示
- 任务列表：进行中（进度条）、完成（✓ 动画）、失败（⚠️ 重试）。
- 全部完成时的成功提示动画。

## 4. 平台差异

| 功能 | 移动端 | 桌面端 |
|------|--------|--------|
| 主要来源 | 云端/蓝牙/WiFi/Mac/Win | 本机文件系统 + WiFi/云端 |
| 蓝牙 | 支持（需权限） | 一般不提供 |
| 文件选择 | go_router 系统/第三方选择器 | 原生打开对话框 |
| 权限 | 存储/蓝牙/网络 | 网络/麦克风(如需) |

## 5. 动画要求
- 来源卡片点按：缩放按压反馈。
- 进度更新：`AnimatedFractionallySizedBox` / 进度条平滑。
- 完成项：✓ 淡入 + 微弹。
- 失败项：⚠️ 抖动提示（可选）。

## 6. 实现架构
- `ImportService` 统一调度各来源导入任务（队列）。
- `ImportTaskRepository` 持久化任务状态。
- 各来源实现为 `ImportSource` 策略（Cloud/Bluetooth/WiFi/LAN/File）。

## 7. 验收要点 / 测试用例范围
- 各来源入口可进入、权限引导正确。
- 进度/完成/失败/重试正确。
- 导入后元数据扫描并出现在播放列表。
- 批量与队列顺序正确。
- 完整用例见《测试用例/导入页面_测试用例.md》。
