# 05 · 设置页面 需求文档

> 版本：v1.0 ｜ 关联构架：整体构架.md ｜ 平台：通用

---

## 1. 功能概述

设置页面（移动端底栏第 3 项 / 桌面端左侧导航第 3 项）提供常规设置：**主题切换、语言（中/英/日）** 以及播放、存储等偏好。

## 3. 功能需求

### 3.1 主题切换
- 选项：浅色 / 深色 / 跟随系统。
- 切换即时生效，含过渡动画（`AnimatedTheme` 颜色淡变）。
- 遵循整体构架 Design Token。

### 3.2 语言（中/英/日）
- 支持 **中文（默认）/ English / 日本語**。
- 切换即时生效并持久化（不必杀进程）。
- 基于 `flutter_localizations` + `intl`，文案集中管理。

### 3.3 减弱动态效果
- 开关控制全局动画（节拍变色、旋转封面等）；开启后降级为静态/淡入。

### 3.4 其他设置
- 播放：默认音量、均衡器/音质（可选，交由引擎支持度）。
- 存储：缓存清理（显示占用，点击清理并反馈）。
- 标签管理：入口跳转到标签管理（见 01 播放列表）。
- 关于：版本号、开源许可。

## 4. 平台差异
- 桌面端：设置可能以对话框/独立窗口形式呈现（可选），内容一致。
- 移动端：表单列表 + 底部弹窗选择。

## 5. 动画要求
- 主题切换：全页颜色 `AnimatedTheme` 平滑过渡。
- 开关：iOS 风 `CupertinoSwitch`。
- 列表项进入：淡入 + 位移动画。
- 语言弹窗：自下而上 + 毛玻璃。

## 6. 数据模型
- `AppPreferences { themeMode, locale, reduceMotion, defaultVolume, ... }`
- 持久化：`shared_preferences` 或本地存储。

## 7. 验收要点 / 测试用例范围
- 主题三态即时生效、持久化。
- 语言中/英/日切换全部文案变化、持久化。
- 减弱动态效果生效。
- 清理缓存反馈。
- 完整用例见《测试用例/设置页面_测试用例.md》。
