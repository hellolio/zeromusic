## 二、覆盖范围

- 主题三态（浅色/深色/跟随系统）切换即时生效、持久化、App 级跟随。
- 语言中/英/日切换：全部文案即时变化（含弹层标题与系统 Material 文案）、持久化。
- 默认音量：滑杆调整写回偏好、经 `AudioEngine.setVolume` 联动真实引擎。
- 背景效果：三档（省电/均衡/绚彩）选择、即时生效并持久化、启动载入。
- 关于：版本号、开源许可入口。
- 持久化层：`SharedPreferencesStore` 真实往返（save/load 保真、无数据时读默认值）。
- 「账号/退出登录」「缓存清理」本版不开放，不覆盖。

## 三、前置条件

- 数据：内置 `FakeDataLayer`（widget 测试不触达 drift 与真实平台插件）。
- 环境：`wrapApp` 注入 `FakeAudioEngine` + `InMemoryPreferencesStore`；SharedPreferences 保真测试用 `SharedPreferences.setMockInitialValues`。
- 测试眉头尺寸（移动 800x600 / 桌面 1400x900），按图标定位导航，保持 locale 无关。

## 五、用例明细（与上表编号一一对应）

### TC-01：设置页渲染分组与当前值
- **前置条件**：默认偏好（跟随系统 / 无语言 / 不减弱动效 / 音量 1.0）。
- **操作步骤**：
  1. 移动布局 pump 应用，点底栏 ⚙️（`Icons.settings_outlined`）。
- **预期结果**：`SettingsPage` 渲染；分组 Appearance / Language / Playback / About 与全部行（Theme、Reduce Motion、Default Volume、Open Source Licenses、Version）可见；值 System / English / 1.0.0 各一处。
- **异常/边界**：兜底空库默认 1.0 音量、默认语言。
- **实测结果**：□ 通过 □ 失败（失败原因：____）

### TC-02：主题切换浅色即时生效并持久化
- **前置条件**：`InMemoryPreferencesStore`。
- **操作步骤**：
  1. 点 `settings-theme` 行。
  2. 弹层选「Light」。
- **预期结果**：`preferencesProvider` themeMode=light；`store.lastSaved.themeMode`=light；`MaterialApp.themeMode`=light（即时生效）。
- **异常/边界**：弹层标题 Theme 与行值 System 并存，勿用 text 定位冲突项。
- **实测结果**：□ 通过 □ 失败（失败原因：____）

### TC-03：主题切换深色即时生效并持久化
- 同 TC-02，选「Dark」→ themeMode=dark、已落盘。

### TC-04：主题选择桌面端锚点菜单
- **前置条件**：桌面尺寸 1400x900。
- **操作步骤**：NavigationRail 进入设置 → 点主题行 → 选「Dark」。
- **预期结果**：弹 anchor 菜单（showMenu）；选择后 themeMode=dark。

### TC-05：语言切中文全部文案变化并持久化
- **前置条件**：默认英文；`InMemoryPreferencesStore`。
- **操作步骤**：点 `settings-language` 行 → 弹层选「中文」。
- **预期结果**：AppBar 变「设置」、分组变「外观」等；locale.languageCode=zh、已落盘；弹层仍可打开且选项原文显示。
- **实测结果**：□ 通过 □ 失败（失败原因：____）

### TC-06：语言切日本語全部文案变化并持久化
- 步骤同 TC-05，选「日本語」→ locale.languageCode=ja、已落盘、文案切换为日文。

### TC-07：启动载入已持久化偏好
- **前置条件**：预置 `AppPreferences(themeMode: dark, locale: ja, reduceMotion: true, defaultVolume: 0.6)` 的 InMemory 存储。
- **操作步骤**：直接切到设置页。
- **预期结果**：主题值显示「ダーク」、语言值「日本語」、音量 60%、减弱动效开关为开。

### TC-08：减弱动效开关翻转并持久化
- **前置条件**：默认关。
- **操作步骤**：点 `CupertinoSwitch` 一次，再点一次。
- **预期结果**：第一次 reduceMotion=true 且落盘；第二次 false 且落盘。

### TC-09：默认音量滑杆联动引擎
- **前置条件**：注入外界可读的 `FakeAudioEngine`。
- **操作步骤**：向左拖动 `Slider`。
- **预期结果**：`defaultVolume` 较拖前减小；`engine.lastVolume == defaultVolume`（引擎音量同步）。
- **实测结果**：□ 通过 □ 失败（失败原因：____）

### TC-10：SharedPreferencesStore 真实往返
- **前置条件**：`SharedPreferences.setMockInitialValues({})` 纯 Dart test。
- **操作步骤**：save(ThemeMode.dark, ja, true, 0.35) → load。
- **预期结果**：全部字段保真；空库 load 返回默认 themeMode=system / locale=null / reduceMotion=false / defaultVolume=1.0。

### TC-11：均衡器降级「不支持」
- **预期结果**：行值显示「Not supported」（en）/「不支持」（zh）/「未対応」（ja）；点击打开均衡器弹层，
  仅显示不支持说明文案。均衡器完整用例见《均衡器_测试用例.md》。
- **实测结果**：☑ 通过

### TC-12：背景效果档位切换并持久化
- **前置条件**：`InMemoryPreferencesStore`（默认均衡）。
- **操作步骤**：
  1. 点 `settings-background-effect` 行。
  2. 弹层选「Vivid」。
- **预期结果**：`preferencesProvider` backgroundEffect=vivid；`store.lastSaved.backgroundEffect`=vivid；行值变「Vivid」。
- **异常/边界**：三档选择均为一次性写盘，不依赖主题/语言。
- **实测结果**：☑ 通过

### TC-13：启动载入已持久化背景效果档位
- **前置条件**：`InMemoryPreferencesStore(AppPreferences(backgroundEffect: powerSaver))`。
- **操作步骤**：直接切到设置页。
- **预期结果**：行值显示「Power Saving」，`preferencesProvider` backgroundEffect=powerSaver。
- **实测结果**：☑ 通过
