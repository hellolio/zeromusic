# UI 微调 2 · 测试用例

> 用途：本轮 UI 微调（玻璃雾色调 / 弹窗雾色带 / 均衡器弹窗宽度 / 桌面侧栏去玻璃 / 桌面迷你条收窄）的用例设计与实测归档。
> 关联：01–05 各页面文档的弹窗、底栏、迷你条、侧栏相关章节。

## 一、用例信息

| 项 | 内容 |
|----|------|
| 功能模块 | 玻璃视觉与桌面布局微调（UI 微调 2） |
| 关联需求文档 | 01/02/03/05 相关章节 |
| 编写日期 | 2026-09-21 |
| 目标平台 | ☑ 移动端 ☑ 桌面端 |

## 二、覆盖范围

覆盖：底栏/迷你条玻璃雾基色分模式（浅色更白、深色更黑）、播放页队列/音量弹窗去除雾色带（回归统一灰雾玻璃）、均衡器弹窗宽度与其他弹窗一致、桌面侧栏导航项去液态玻璃（实色 pill）、桌面迷你条宽度收窄（480 → 380）。
不覆盖：弹窗业务逻辑（选择/保存行为）、底栏滑块手势、迷你条切歌手势（未改动）。

## 三、前置条件

- 测试环境：widget 测试（fake 数据层 + FakeAudioEngine + 强制减弱动效）；手工验证在 iOS 模拟器 / macOS 桌面。
- 均衡器用 FakeEqualizer（`supported = false` 分支）。

## 五、用例明细（实测结果）

- **TC-01**：☑ 通过（`widget_test.dart`「底栏与迷你条：雾基色按明暗模式取白/黑基」——浅色主题 fogColor = 白、深色主题 fogColor = 黑，且玻璃弹窗不传 fogColor 回归不受影响）。
- **TC-02**：☑ 通过（`player_page_test.dart`「队列弹窗 GlassOverlay 不传 tint（回归）」；曾反向验证：恢复 tint 后该测试失败，即雾渐变中段为黑色 band）。
- **TC-03**：☑ 通过（`player_page_test.dart`「音量弹窗 GlassOverlay 不传 tint（回归）」）。

- **TC-05**：☑ 通过（`widget_test.dart`「桌面端：侧栏导航项不再使用液态玻璃」：项内 findsNothing GlassOverlay，选中项 DecoratedBox 有实色背景）。
- **TC-06**：☑ 通过（`mini_player_test.dart`「桌面端：迷你条胶囊宽度收窄为 380 且保留液态玻璃」）。
