## 二、覆盖范围

覆盖：跨窗口消息编解码、行状态计算与推送节流、控制器开关编排（fake 窗口 API）、歌词条 UI 各状态与交互动画回调、几何纯函数（尺寸/默认位置/出屏钳制）、设置页「桌面」分组（仅桌面可见 + 开关联动 + 字号 + 恢复位置）。
不覆盖（留待桌面端手工验证）：真实 OS 级窗口的透明/置顶/不抢焦点/拖动/跨显示器表现（见第十一节手工清单）。

## 三、前置条件

- 可自动化：Flutter 测试环境（locale 默认英文）、`FakeAudioEngine`、内存偏好存储、内存假数据层、fake `LyricWindowApi`；widget 测试不触碰真实平台窗口。
- 手工：macOS / Windows / Linux 桌面端，若干带 LRC 歌词与无歌词曲目。

## 六、手工验证清单（桌面端）

- [ ] macOS：背景全透明（仅见文字与投影，无任何底色）、置顶于普通应用之上、无边框无阴影、不进 Dock、点击不抢焦点、主窗口最小化后仍滚动、跨 Space（全屏应用上方）显示。
- [ ] macOS：首次开启 / 重启自动恢复 → 歌词条**立即出现**（ready 握手后 show，修复前首开永不显示）。
- [ ] 关闭后再开启 → 歌词条显示当前行（修复前展示关闭前的陈旧行）。
- [ ] Windows：透明 + 置顶 + 不进任务栏；已知限制：点击会激活窗口（设置页提示）。
- [ ] Linux：有合成器时透明；无合成器降级不 crash。
- [ ] 平时只见歌词：无背景无关闭按钮；鼠标悬停 → 淡底浮现 + ✕ 出现，可拖拽可点击关闭。
- [ ] 拖动定位顺滑、重启恢复、拖出屏幕后重启拉回。
- [ ] 行数变化（间奏/最后一句）时窗口高度自适应收缩，当前行位置不跳动。
- [ ] 开关/字号/恢复位置即时生效；开关关闭时设置页只剩一行；重启记忆。
- [ ] 主窗口关闭（退出应用）→ 歌词条随进程一并关闭。
