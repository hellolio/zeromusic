# 02 · 播放页面 需求文档

> 版本：v1.0 ｜ 关联构架：整体构架.md ｜ 平台：通用

---

## 1. 功能概述

播放页面为**全屏沉浸式**页面，风格对标 Apple Music。由迷你播放条上滑/点按进入，可下拉收起返回原页面。核心亮点：**背景随音乐节拍动态变色**（"蹦迪"效果），并提供完整播放控制、打开播放队列、显示歌词等功能。

## 3. 功能需求

### 3.1 进入 / 退出
- 入口：迷你播放条**上滑**或**整体点按**进入（移动端）；桌面端由左侧导航「播放页」或迷你条点按进入（嵌入式页面，无独立路由）。
- 退出：
  - **移动端（全屏路由）**：顶部有一根 Apple Music 风格的**细横线**，点按收起返回进入前的页面；下拉手势（待实现）。
  - **桌面端（嵌入式，存在左侧栏）**：顶部**不显示**收起条——关闭播放页无意义，通过左侧导航切换离开。
- 进出场为自下而上的滑动 + 背景过渡动画。

### 3.2 节拍变色背景（核心动效）
- 有封面：背景为封面模糊大图。
- 无封面：整层高斯模糊（Apple 磨砂风）上叠加由曲目色板派生的**动态径向光斑**，光斑漂移营造氛围。
- 光斑数量与动画开销由设置页「背景效果」档位控制：省电=5 / 均衡=8 / 绚彩=12（见 05 设置页面 3.4）。
- 播放时呼吸漂移、暂停时变慢，播放结束复归静态默认色。

### 3.3 旋转封面
- 播放时封面缓慢旋转（`RotationTransition`），暂停时减速/停止。

### 3.4 播放控制
- 上一首 / 播放暂停 / 下一首。
- 进度条：显示当前/总时长，可拖动 seek（圆形拖动手柄，放大反馈）。
- 播放模式：顺序 / 循环 / 单曲循环 / 随机（🔁 切换）。

### 3.5 打开播放列表（队列）
- 点「播放列表 ▾」下拉展开当前播放队列。
- 队列内点某首即切换播放；当前曲目高亮。

### 3.6 歌词
- 点「📄 歌词」打开歌词页（按钮图标为**文稿图标** `CupertinoIcons.doc_text`，区别于麦克风）。
- 支持 LRC 文件解析（自动/手动匹配）。
- 歌词随播放进度**逐行高亮**（卡拉 OK 滚动效果）。
- 无歌词时显示"暂无歌词"并提供联网/手动导入入口（可选）。

### 3.7 其他
- 喜欢切换（红心动画）。
- 睡眠定时（可选）。
- 更多（⋯）：查看专辑、去艺人页、编辑信息等。

## 4. 平台差异

| 功能 | 移动端 | 桌面端 |
|------|--------|--------|
| 进入 | 迷你条上滑 | 左侧导航「播放页」或迷你条点按 |
| 退出 | 顶部细横线点按 / 下拉手势 | 嵌入式无收起条，左侧导航切换 |
| 顶部收起条 | 显示（细横线） | 不显示（嵌入模式关闭无效） |
| 进度条 | 触摸拖动 | 鼠标拖动/双击定位 |
| 下一条快捷切换 | 无 | 键盘方向键（可选） |

## 5. 动画要求
- 背景变色：节流更新（≤30fps 视觉更新即可），`AnimatedContainer` 插值。
- 播放/暂停：图标 `AnimatedSwitcher`。
- 进度拖动：回弹 + 气泡内实时显示时间。
- 歌词滚动：`AnimatedScrollView` / LRC 行高亮淡入。
- 进入退出：上滑进场、下拉收起，全程可中断。

## 6. 数据模型（草案）
- 复用 `AudioService` 播放状态流。
- 歌词：`LyricsLine { time, text }`，LRC 解析为列表。

## 7. 验收要点 / 测试用例范围
- 进出场动画、手势。
- 背景节拍变色正确、不卡顿、可关闭。
- 控制按钮、播放队列、歌词高亮。
- 进度拖动 seek 准确。
- 完整用例见《测试用例/播放页面_测试用例.md》。
