# 06 · 视频播放 需求文档

> 版本：v1.0 ｜ 关联构架：整体构架.md ｜ 平台：通用

---

## 1. 功能概述

在音乐播放器基础上提供**视频播放能力**：可播放本地视频文件（`.mp4 / .mkv / .webm / .mov` 等），共享媒体库作为"视频"类型条目。UI 风格与整体一致。

## 2. 界面布局

```
┌─────────────────────────────────────────┐
│  播放列表页（视频条目，与歌曲同列表）    │
│  · 类型标识为「视频」                   │
├─────────────────────────────────────────┤
│  视频播放页（全屏）                     │
│  ┌─────────────────────────────────┐   │
│  │         视频画面（16:9）        │   │
│  │  ▶ 播放/暂停  ⏮ ⏭  ⏯         │   │
│  │  ─────●──────── (进度条)        │   │
│  │  全屏/退出 · 音量 · 倍速        │   │
│  └─────────────────────────────────┘   │
│  下方：关联歌词/简介（可选）           │
└─────────────────────────────────────────┘
```

## 3. 功能需求

### 3.1 视频媒体管理
- 视频作为媒体库一种类型，进入播放列表页可筛选「视频」。
- 导入流程复用 04 导入页，识别视频格式并分类。

### 3.2 播放器功能
- 播放 / 暂停 / 停止、进度拖动 seek。
- 上一段 / 下一段（或视频内快进快退）。
- 音量、**倍速**（0.5×–2×）。
- 全屏切换（旋转适配），字幕显示（可选）。

### 3.3 格式支持
- mp4 / webm / mkv / mov / avi（按所选引擎能力，桌面 `media_kit` 支持度更高）。

### 3.4 迷你条 & 播放页关系
- 视频播放时迷你条可显示节目标题；点按进入视频播放页而非音频播放页。

## 4. 平台差异

| 功能 | 移动端 | 桌面端 |
|------|--------|--------|
| 播放引擎 | `video_player`（硬件解码） | `media_kit`（libmpv）更稳 |
| 全屏 | 旋转 + 隐藏系统栏 | 自适应窗口 / Esc 退出 |
| 格式兼容 | 平台编解码决定 | 编解码更全 |

## 5. 动画要求
- 控制条自动隐藏/出现：淡入淡出。
- 倍速选择：胶囊弹窗 + 缩放。
- 全屏过渡：`AnimatedRotation` / 布局过渡。

## 6. 实现架构
- `VideoService` 封装播放引擎，状态流与音频统一由 `MediaPlaybackService` 抽象（媒体类型区分音/视频）。

## 7. 验收要点 / 测试用例范围
- 视频导入并归入视频分类。
- 播放/暂停/seek/倍速/全屏正常。
- 移动/桌面引擎各自可用。
- 完整用例见《测试用例/视频播放_测试用例.md》。
